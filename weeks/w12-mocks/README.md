# Week 12: mocks

Five full rounds under real conditions: timer, blank file, talking out loud, recorded. Each day
ends with a score, the level it signals, and the single biggest gap. If you can, do at least two
of them with a human (a friend at a big company, a paid mock platform, an ex-colleague): self-grading
is useful, an outside interviewer is better.

Primer: `knowledge/13-question-bank.md` (mixed questions for warm-up, any day).

| Day | Round | Format |
|---|---|---|
| d1 | coding A | 2 problems, 35 min total, blank functions, narrate (W1 protocol) |
| d2 | coding B | 2 problems, 35 min total; review a candidate's solution |
| d3 | system design + ML design | two 45-min written designs, rubric-graded |
| d4 | behavioral + project deep dive | 45 min each, scripted questions, scorer |
| d5 | take-home + pair programming | a 4-hour take-home spec + a 45-min pairing session on existing code, then the final retro |

## Rules for mock days
1. Timer visible. Stop at the bell, even mid-line.
2. Record audio. Listen to 5 minutes of it the same day: count filler words, silences > 20 s, and unverified claims.
3. Grade with the rubric before reading any model answer.
4. Write the biggest gap in `PROGRESS.md`. The next week's practice targets it.
